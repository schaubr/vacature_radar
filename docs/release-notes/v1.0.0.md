First release of Vacature Radar: a personal macOS menu-bar app that watches Flemish social-sector job sites, collects the vacancies and scores each one against your LinkedIn profile with Claude.

## Downloads

| File | For |

Requires macOS 13 Ventura or newer. Nothing else needs to be installed.

## Install

1. Open the `.dmg` and drag Vacature Radar onto the Applications shortcut.
2. First launch: the app is not signed with a paid Apple Developer ID, so macOS says it cannot verify the developer. Open System Settings > Privacy & Security, scroll down and choose Open Anyway. This is needed once. Alternatively, in Terminal: `xattr -dr com.apple.quarantine "/Applications/Vacature Radar.app"`.
3. In Settings, add your Anthropic API key (and optionally an OpenRouteService key for travel times). In Profile, import your LinkedIn data export (`.zip`) or profile PDF and fill in your preferences.

## What's in 1.0.0

- **Sources:** VDAB (two searches), VVSG, Jobsolutions, Fiola vzw, Socius and Helan, plus CAW and Zorgnet-Icuro (off by default). Add any listing page yourself; the Test button shows what it finds, explains empty results and detects hosted job portals such as Jobtoolz.
- **Extraction:** RSS feeds, structured job data, saved page patterns, and Claude learning a new site's layout when needed. A hidden browser handles JavaScript sites and embedded job widgets. robots.txt is respected and each site gets at least 3 seconds between requests.
- **Scoring:** Claude Opus 5.5 judges each vacancy against your profile (diploma, experience, skills, preferences), with reasons, gaps and knock-outs; Claude Sonnet 5.5 learns page layouts. A monthly budget cap (default 5 USD) stops all Claude calls when reached. Thumbs up/down feedback tunes later scores.
- **Travel time:** car travel time from your home location via OpenRouteService, shown on every vacancy, sortable and filterable, and used in the score.
- **Inbox:** statuses (new, seen, interested, applied, dismissed, closed), the same job on several sites shown once, vacancies closed automatically when they disappear or pass their deadline (never the ones you marked), and notifications for strong matches.
- **Language:** English or Nederlands, switchable instantly from the sidebar or Settings. It also sets the language of Claude's explanations.
- **Privacy:** your data stays in `~/Library/Application Support/Vacature Radar`; API keys are stored encrypted with the macOS Keychain. Only page fetches, Claude API calls and OpenRouteService lookups leave your Mac.

## Known limitations

- Not notarized by Apple, hence the one-time warning on first launch.
- Zorgnet-Icuro's vacancies come from a Jobat widget behind Cloudflare bot protection. It usually works from a home connection; if Test shows nothing, its hint says why.
- Travel times are for the car without traffic; public transport is not supported.
- Large sites are read partially: Helan's 5 newest pages, Socius's 3 pages. At most 25 new vacancies per source are scored per scan; the rest show as Skipped and can be scored by hand.
- Texts stored before a language switch (explanations, log lines) keep their original language until re-scored.
